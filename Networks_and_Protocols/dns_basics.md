# Домены, делегирование и DNS

## 1. Что такое домен

- **Домен (доменное имя)** — удобное для человека буквенное обозначение IP-адреса. Компьютеры общаются по IP, например `93.184.216.34`, а человеку проще запомнить `example.com`.
- **Структура:** читается справа налево. `.com` — домен верхнего уровня (TLD), `example` — домен второго уровня (арендуется), `www` — поддомен.

## 2. Делегирование домена

**Простыми словами:** это передача прав на управление зоной домена от регистратора к твоим DNS-серверам.

**Технически:**
1. Покупаешь домен у регистратора (например, Reg.ru или Namecheap). Регистратор вносит запись в реестр домена верхнего уровня (TLD).
2. В панели регистратора указываешь NS-серверы, например `ns1.beget.com` и `ns2.beget.com`.
3. Регистратор передаёт эту информацию в реестр зоны `.com` или `.ru`.
4. Когда кто-то ищет твой домен, корневые серверы отвечают: «IP не знаю, но за этот домен отвечают серверы `ns1.beget.com`. Идите к ним».

**Суть:** ты говоришь глобальному интернету: «Я не хочу сам держать DNS-сервер — все вопросы по моему домену передавайте хостингу».

## 3. Утилиты whois и dig

| Утилита | Что показывает | Зачем нужно |
|---|---|---|
| `whois` | Административную информацию: регистратор, даты регистрации и окончания, статус, контакты владельца (если не скрыты) | Проверить владельца, срок домена, кому жаловаться на спам |
| `dig` | Техническую информацию: A-запись, MX, NS, TXT и т.д. | Диагностика: правильный ли IP, почтовые серверы, NS-серверы |

## 4. Основные DNS-записи

| Запись | Назначение | Пример |
|---|---|---|
| `A` | Связывает домен с IPv4-адресом | `example.com -> 192.0.2.1` |
| `MX` | Указывает сервер, который принимает почту. Чем меньше число, тем выше приоритет | `example.com -> mail.example.com (10)` |
| `NS` | Указывает серверы, которые хранят настройки зоны | `example.com -> ns1.hosting.com` |

## Практика

```bash
whois phone-test.ru
```

Пример:
- `registrar: BEGET-RU`
- `created: 2021-12-07T08:29:53Z`
- `paid-till: 2026-12-07T08:29:53Z`
- `free-date: 2027-01-07`

```bash
dig A phone-test.ru
```

Пример:
- `A — 45.130.41.127`

```bash
dig MX phone-test.ru
```

Пример:
- `MX 10 mx1.beget.com.`
- `MX 20 mx2.beget.com.`

```bash
dig NS phone-test.ru
```

Пример:
- `NS harlee.ns.cloudflare.com.`
- `NS sonny.ns.cloudflare.com.`
